# Dashboard PDRB dan Lapangan Kerja Provinsi 2021–2025

Dashboard interaktif untuk ACTION 2026 (Infografis Tingkat Mahasiswa). Membandingkan laju PDRB, penyerapan tenaga kerja, dan pengangguran terbuka di 38 provinsi Indonesia.

Buka `index.html` melalui GitHub Pages (lihat alamat pada kolom "About" repositori ini).

## Isi
- Peta provinsi dengan slider tahun dan delapan indikator.
- Tipologi kuadran PDRB × penyerapan kerja (32 provinsi non-Papua, plus Papua Raya).
- Profil provinsi, ringkasan hasil analisis, dan tabel data.

## Sumber data
- Badan Pusat Statistik (bps.go.id): Laju PDRB ADHK 2010 menurut provinsi; PDRB (milyar rupiah); PDRB triwulanan menurut lapangan usaha; Sakernas Agustus 2021–2025 (TPT, TPAK, jenis kegiatan, status pekerjaan, lapangan usaha); proporsi lapangan kerja informal; tingkat setengah pengangguran.
- Peta: [GeoJSON 38 provinsi](https://github.com/denyherianto/indonesia-geojson-topojson-maps-with-38-provinces), lisensi data CC BY 4.0. Sumber asli batas wilayahnya tidak dinyatakan penyedia, sehingga peta hanya ilustratif.

## Catatan
Kuadran dan klaster bersifat deskriptif dan eksploratif, bukan bukti sebab-akibat. Data Sakernas adalah estimasi survei dengan galat sampling.
